Review-hardening invariants (regression coverage lives in `tests/test_review_regressions.py`; keep them true when editing the named areas):
- `AgentLoop` must leave a provider-valid transcript on every exit: each tool call gets a tool message (`tool_not_executed` for calls that did not run), concurrent batches use `gather(return_exceptions=True)` and keep completed results, `LoopDetector` is copied/reset per run, and idempotency keys include an argument digest. Only run-deadline expiry (tracked by `deadline_hit`) may end a run as `timeout`; a `TimeoutError` from a tool or provider is an ordinary failure. OpenAI chat streaming must send `stream_options={"include_usage": True}` so token budgets and ledgers see usage.
- Provider payload helpers: never define the same private helper name twice in `agent_rt.py` (the later definition silently shadows the earlier one — JSON tool results and assembled context were once dropped this way), and conversion caches must hold strong references to their keys rather than `id()` values.
- CLI: workspace tools use `error_behavior="return_error"`; `WorkspaceCodeTools` refuses writes under `.git/` and to `.gitattributes`/`.gitmodules`, and the Git tools fail closed when repo-local/worktree/command-scope `filter.*.clean|smudge|process` config exists. Approval previews must say how much content is hidden and print model-controlled values with markup disabled.
- Sandbox: `_native_preexec` must clear supplementary groups before `setgid`/`setuid` and native execution derives the account gid (or requires `AGENT_RT_SANDBOX_GID`) instead of inheriting root's. Native and Docker execution go through `_collect_process_result` (bounded capture, kill + reap on cancel/timeout; Docker names its container and runs `docker kill`). Docker keeps `--cap-drop ALL`, `no-new-privileges`, and `--memory-swap` equal to memory, validates `workspace_root`/cwd, and supports `AGENT_RT_SANDBOX_DOCKER_USER`/`AGENT_RT_SANDBOX_DOCKER_READ_ONLY`. `SandboxResourceLimits` rejects `0` memory/process limits, E2B/microsandbox create one sandbox per session under a lock and expose `close_session`, and `SandboxNetworkPolicy.allows` rejects backslash/whitespace/control characters. Snapshots only cover the in-process workspace; do not describe them as disk snapshots.
- API server: rate-limit identity comes from `AgentRTAPIServer.request_identity` (verified credential or client address only); `RateLimiter` prunes expired keys; `authorize_value` compares bytes; all endpoints (including WebSocket) validate bodies and generation settings through `prepare_run` before streaming begins; unsupported content parts raise; non-completed runs map to `length`/`max_tokens`/`stop` and never expose unexecuted tool calls; `/health` is minimal for unauthenticated callers when keys are configured.

Second-pass hardening invariants (also covered by `tests/test_review_regressions.py`):
- `_validate_structured_value` implements the documented JSON Schema subset (types lists, bounds, `pattern`, `const`, `anyOf`/`oneOf`/`allOf`/`not`, local `$ref`, `additionalProperties` schemas); keep Python and TypeScript keyword support identical. `integer` accepts integral floats.
- `ContextAssembler` puts only workflow state and `trusted` items in a system message; `untrusted` items are a user-role `untrusted_context` data message, and offloading must preserve `trust`. CLI compaction summaries are user-role data.
- Provider conversion: media parts go through `_openai_content_parts`/`_anthropic_content_blocks` (and `responses_input_items` for WebSocket); unsupported media raises. Anthropic thinking blocks are `ContentPart(type="json", mime_type=PROVIDER_STATE_MIME)`, replayed first in assistant turns, skipped by `_message_text`, `_extract_structured_output`, and OpenAI payloads. `response.incomplete` is a truncation with `finish_reason="length"`. Server rate-limit waits are capped by `MAX_RATE_LIMIT_BLOCK_SECONDS`.
- `ToolRegistry.register` validates handler arguments before mutating state, deferred registrations carry handlers, `load()` goes through `register(replace=True)`, and output guardrails/post-call hooks that raise emit `on_error` plus a terminal `error` audit event. Output guardrails, tool filters, and failure classifiers may expose an `acall` twin (see `_call_maybe_async`); Decision hooks use `_with_async_twin` so blocking HTTP stays off the event loop.
- `InMemoryFileSystem.delete` rejects the root (use `clear()`/`WorkspaceFiles.clear()`); `glob` is segment-aware; `apply_unified_patch` never skips in-hunk header-looking lines. `PrivacyRedactor` matches normalized key suffixes. `TenantContext` rejects `::`. `SideEffectTransaction.commit` runs all compensations and annotates the re-raised error. Registration guards must return a report (`None` blocks) and scans canonicalize Unicode first.
- MCP: `MCPClient` enforces advertised capabilities; `MCPAccessPolicy` raises when requirements exist without authentication and applies `CapabilityGrant.tools` to tool names when non-empty.
- Queues/tasks: `InMemoryWorkQueue.release_expired` dead-letters exhausted items, `InMemoryScheduler.due` jumps arithmetically, `EventTriggerDispatcher` marks events seen after all rules are enqueued, `BackgroundTaskManager.cancel` records pre-start cancellation and `wait` is shielded, `AgentLoop` event ids skip taken ids, `ResponseCache` is bounded (`max_entries`), `SingleFlight` removes entries on task completion. Skill loading checks sizes before reading and accepts a closing `---` at EOF; the CLI warns when a workspace skill shadows a global one and writes transcripts owner-only (0600/0700).

Third-pass hardening invariants (covered by `tests/test_review_regressions.py`):
- `once` approvals are bound to the exact call: `ApprovalGrant.arguments_json` holds the canonical arguments and `InMemoryApprovalStore.decision` skips a `once` grant whose arguments differ (without consuming it); `ApprovalManager` only passes `arguments_json` to stores whose `decision` accepts it. A resumed `AgentLoop` executes calls left as `tool_not_executed`/`waiting_for_approval` placeholders (re-checking approval) before consulting the model, so approvals are never orphaned by a new call id.
- Malformed model tool-argument JSON never aborts a run: provider adapters use `_provider_tool_call`, which sets `ToolCall.argument_error`; the registry refuses such calls and the loop returns a `tool_argument_validation` result to the model. API run failures (as opposed to request validation) return 500, never `400 Invalid request`.
- Catch `(asyncio.TimeoutError, TimeoutError)` around `asyncio.wait_for`; on Python 3.10 they are different classes (the API execution queue leaked slots otherwise).
- Sandbox/native launchers: privileged launchers run with a fixed environment and absolute paths; model-supplied environment (`PATH`, `LD_PRELOAD`) is applied only after the privilege drop. Keep this in parity with TypeScript.
- Retrieval adapters without filter support (Milvus, Weaviate) must raise when `query.filters` is set; never run an unfiltered search that a caller scoped for isolation.
- Context compaction summaries are `user`-role messages labelled as data (never `system`), and compaction/`max_messages` selection never separates an assistant tool call from its tool results.
- Registration-safety content is serialised with `ensure_ascii=False` so Unicode canonicalisation sees real characters; skill tool `input_schema` is scanned too.
- `TenantQuotaManager.release()` never enforces quota limits. `RetainedEventStore` sequences come from a per-task monotonic counter, not the visible stream length. `MicrosandboxBackend` refuses a network-mode change after the microVM exists.
- Compat agents (LangChain/LlamaIndex) never execute a tool call whose arguments were malformed (`ToolCall.argument_error`, or non-object/invalid JSON): they reply with a "Tool call rejected" tool message. A handoff or return-direct exit still answers every tool call in the assistant message. `Memory.get` context is a user-role data message, `Memory(chat_store=…)` persists live messages on `put()`, and eviction never strands tool replies.
- MCP compat: `allowed_tools` must be a name list (or `{tool_names}`) and `require_approval` must be absent or `"never"`; unsupported shapes raise instead of exposing every tool. Colliding sanitized MCP function names raise.
- Prompt templates in compat adapters render through `ext/compat/_format.py::safe_format` (plain variable names only; no attribute/index/positional fields).
- OpenAI Responses WebSocket: the continuation id is cleared before each request and re-armed only after a completed response; a request abandoned without `stream_id` drops the connection; inner event generators are closed with `aclosing`.
