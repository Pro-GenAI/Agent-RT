Getting started

Installation

Agent RT ships as a Python package and a TypeScript/Node package. Choose the runtime your application already uses; the core contracts intentionally follow the same mental model in both implementations.

Requirements

RuntimeSupported versionsInstall
Python3.10–3.14pip install agent-rt
Node.js20, 22, 24, or 26npm install agent-rt

Python

python -m venv .venv
source .venv/bin/activate
pip install agent-rt

TypeScript / Node.js

npm install agent-rt

Configure a provider

For OpenAI or an OpenAI-compatible endpoint, configure the model and credentials in the environment.

export OPENAI_MODEL="your-model"
export OPENAI_API_KEY="..."
# Optional:
export OPENAI_BASE_URL="https://your-provider.example/v1"

For Anthropic, set ANTHROPIC_BASE_URL, ANTHROPIC_API_KEY, and ANTHROPIC_MODEL.

Provider-neutral by designAgent code is built against Agent RT contracts. OpenAI, Anthropic, compatible endpoints, Decision models, and custom providers can sit behind that boundary.

Vector databases

No Chroma, Pinecone, Qdrant, Milvus, Weaviate, LangChain, or LlamaIndex package is required for Agent RT's built-in vector retrieval and compatibility adapters. Configure the service through AGENT_RT_VECTOR_DB, AGENT_RT_VECTOR_DB_URL, and AGENT_RT_VECTOR_DB_COLLECTION, then see the vector database guide for backend credentials and framework migration imports.
