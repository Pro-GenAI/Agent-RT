Getting started

Installation

Agent RT ships as a Python package and a TypeScript/Node package. Choose the runtime your application already uses; the core contracts intentionally follow the same mental model in both implementations.

Requirements

RuntimeSupported versionsInstall
Python3.10–3.14pip install agent-rt
Node.js20, 22, 24, or 26npm install agent-rt

Python

python -m venv .venv
source .venv/bin/activate
pip install agent-rt

TypeScript / Node.js

npm install agent-rt

Configure models

Agent RT is configured with one YAML file: agent-rt.yaml in the current folder, ~/.agent-rt/config.yaml in your home folder, or any path passed with --config / load_config(path). Declare as many models as you need; secrets are referenced as os.environ/NAME and are the only thing read from the environment.

model_list:
  - model_name: my-model
    agent_rt_params:
      model: openai/your-model          # or anthropic/...; add api_base for compatible endpoints
      api_key: os.environ/OPENAI_API_KEY

Repeating a model_name adds an ordered fallback. See the configuration reference and the example file.

Provider-neutral by designAgent code is built against Agent RT contracts. OpenAI, Anthropic, compatible endpoints, Decision models, and custom providers can sit behind that boundary.

Vector databases

No Chroma, Pinecone, Qdrant, Milvus, Weaviate, LangChain, or LlamaIndex package is required for Agent RT's built-in vector retrieval and compatibility adapters. Declare services in vector_store_registry (several are allowed), then see the vector database guide for backend credentials and framework migration imports.
