# Privacy & terms

This page covers the Agent RT website. The Agent RT software is a library you run yourself, under the MIT license.

Updated 29 October 2026

## Privacy

- **No direct visitor data collection.** The site has no accounts, forms, comments, newsletters, analytics, advertising, or embedded third-party content. Agent RT does not use the site to build visitor profiles or collect submissions. The hosting providers may separately process hosting-related data, as described below.

- **No cookies.** The homepage Motion toggle saves one preference (`agent-rt-motion`) in your browser's local storage. It stays on your device and is not sent anywhere.

- **No third-party requests.** Every script, style, and image is served from this site. Links to GitHub, PyPI, and npm lead to those services, which have their own policies.

- **Hosting.** The site is available on GitHub Pages and Cloudflare Pages. GitHub Pages

[logs visitor IP addresses for security](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages#data-collection) , including visits by people without a GitHub account. Cloudflare processes traffic information, which can include IP addresses, when serving its Pages site. See the [GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement) and [Cloudflare privacy policy](https://www.cloudflare.com/privacypolicy/) for their practices.

## Children and personal information

This site provides documentation for developers. It has no signup, age-profile, or submission flow, and does not request dates of birth or information from children. Hosting-related IP logging is described above. Please do not post children's information or other private data in public GitHub issues.

## When you run Agent RT

The software runs in your environment. Depending on your configuration, prompts, files, tool results, and retrieved context may be sent to model providers, memory services, MCP servers, or other connected tools. Sessions, checkpoints, and traces may retain content. Optional observability export has its own destination and settings. Review the services and retention settings you enable; this website notice does not describe or govern an application you or another operator builds with Agent RT.
