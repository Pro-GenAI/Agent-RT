Development

Agent RT keeps the Python and TypeScript runtimes aligned and verifies them across supported runtime versions and operating systems. Use the repository guide as the source of truth for contributor commands.

Python workflow

cd python
uv sync
uv run pytest

TypeScript workflow

cd typescript
npm ci
npm run build
npm test

Cross-platform expectations

CI covers both runtime implementations on Linux, macOS, and Windows. Security and adversarial runtime scans are deterministic and must not depend on live model APIs.

Documentation expectations

Durable architecture and design concepts live under the repository docs/ directory. User-facing capabilities, requirements, packaging, and current workflows stay aligned with the root and package READMEs. The static website under docs/website/ remains dependency-free and has no build step.
