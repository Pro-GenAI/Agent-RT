Privacy & terms

This page covers the Agent RT website. The Agent RT software is a library you run yourself, under the MIT license.

Privacy

  • No direct visitor data collection. The site has no accounts, forms, comments, newsletters, analytics, advertising, or embedded third-party content. Agent RT does not use the site to build visitor profiles or collect submissions. GitHub Pages may separately process hosting-related data, as described below.
  • No cookies. The homepage Motion toggle saves one preference (agent-rt-motion) in your browser's local storage. It stays on your device and is not sent anywhere.
  • No third-party requests. Every script, style, and image is served from this site. Links to GitHub, PyPI, and npm lead to those services, which have their own policies.
  • Hosting. GitHub Pages serves this site and may process visitor IP addresses and request details as part of operating and securing its hosting service. That processing is governed by GitHub's own privacy statement; requests about hosting logs should be directed to GitHub.
