Keep the 65 synthetic cases and mocked tools safe (50 originals, five advanced variants and ten targeted document-body probes), rank 20 test cases first by the checked-in qualitative manifest, run ten by default unless `--limit` overrides, accept the first positional argument `make eval-swarmguard k` for k independent attempts per case with unanimous-only confirmed findings and trial-separated model/Decision caches, and allow a single worker model alias per run via `--subagent-model` or `make eval-swarmguard SUBAGENT_MODEL=alias` (validated against `model_list`, shared by both harnesses, reviewer/Decision unchanged, model-aware separate cache keys), offline unit tests deterministic, and successful LLM/Decision responses cached separately; cache only valid assistant responses and typed completed-empty model-capability markers, never HTTP, rate-limit, network, incomplete, or malformed failures.
