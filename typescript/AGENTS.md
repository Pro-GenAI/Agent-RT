Review-hardening invariants (regression coverage lives in `tests/review-regressions.test.js`, which `npm test` runs; keep them true when editing the named areas):
- `nodeModule()` must load Node built-ins through `process.getBuiltinModule` (or the module's own `require`); code built with the `Function` constructor cannot see `require`, which once made every native/Docker sandbox spawn and OpenLLMetry initialisation fail. Sandbox tests must exercise a real spawn (a stub binary), not only fail-closed paths.
- `AgentLoop` must leave a provider-valid transcript on every exit: each tool call gets a tool message (`tool_not_executed` for calls that did not run), concurrent batches use `Promise.allSettled` and keep completed results, `LoopDetector` is cloned/reset per run, and idempotency keys include an argument fingerprint. OpenAI chat streaming must send `stream_options: { include_usage: true }`.
- Argument validation uses own-property checks (`hasOwnKey`), never `in`, so `constructor`/`toString`/`__proto__` cannot satisfy `required` or slip past `additionalProperties: false`.
- `OpenAIRateLimitGate.wait` sleeps in slices of at most 2^31-1 ms (larger `setTimeout` delays clamp to 1 ms and would busy-loop); `RateLimiter` prunes expired keys.
- Sandbox: backends receive an `AbortSignal` in their execute context and must stop the command on abort (process-group kill for native, `docker kill <name>` for Docker); `runLocalProcess` caps captured output while reading (default 16 MiB). Native uses `setpriv --regid=<derived gid> --clear-groups --no-new-privs` and requires `sandbox.gid` when no passwd gid is found. Docker keeps `--cap-drop ALL`, `no-new-privileges`, and `--memory-swap` equal to memory, validates `workspaceRoot`/cwd, and supports `sandbox.docker_user`/`sandbox.docker_read_only`. Zero `memoryBytes`/`processCount` limits are rejected, E2B/microsandbox create one sandbox per session and implement `closeSession` (surfaced as `SandboxSession.close()`), and `sandboxNetworkAllows` rejects backslash/whitespace/control characters. Snapshots only cover the in-process workspace.
